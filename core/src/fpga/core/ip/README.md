`psram.sv` ist ein asynchroner Controller für die CellularRAM-Chips des Pocket
(AS1C8M16PL-70, `cram0`/`cram1`). Der PlayStation-Core für den Pocket nutzt ihn
unverändert auf echter Hardware.
